# Business Analytics 2026-3 📊

Repository for the **Business Analytics** course corresponding to the 2026-3 academic term, taught by **Juan Nicolás Velásquez Rey** (M.A. in Economics, Universidad de los Andes).

## 📚 Course Description
This course provides a hands-on introduction to data analytics for business decision-making. Students will work with tools such as **R, Excel, Power BI, and SQL**, applying analytical concepts to real-world problems in **digital marketing, finance, and business strategy**.

## 🗂 Repository Structure

- `syllabus/`: Course syllabus and schedule
- `lectures/`: Class materials (slides, scripts, notebooks)
- `datasets/`: Datasets used in class
- `cases/`: Workshops and assignments
- `solutions/`: Solutions (if applicable)
- `utils/`: Helper functions or scripts
-  `sops/`: Setup and download guides (R, RStudio, VS Code, GitHub)

## 🛠 Tools & Technologies

- R & RMarkdown  
- Excel  
- Power BI  
- SQL (basic)
